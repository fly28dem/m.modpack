M.Modpacks / Tutorial

How to
install?

This table will help you quickly get your bearings
and learn how to install Minecraft modpacks.
Good luck!

01. Download

Go to the modpacks page and select the one you like. Click the Download button.


An archive file will be downloaded to your computer.

02. Extracting

Open the archive using WinRAR or 7-Zip.


Move the contents to any folder on your computer.

03. Game folder

If you are using the official game launcher:


Press the Win + R keys. Type `%AppData%` into the field. Navigate to the `.minecraft` directory.


This is your game folder.

04. Data preservation

Copy the data from the .minecraft folder to any convenient location on your computer.


If something goes wrong, you will be able to restore the folder.

05. Install

Move the previously extracted data into the game folder (overwriting existing files).


If this is not your first time installing, we recommend delete all data from the .minecraft folder beforehand.

06. Launch

Launch the game. Select the version for which you have the modpack installed.


Enjoy the game!
